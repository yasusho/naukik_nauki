# ナウキ運び 公式ルール

荷物を運んで港で塩にし、地元へ持ち帰って得点を競うすごろく風カードゲームです。

* **人数 / 時間:** 2〜4人 / 15〜20分
* **手札上限:** 5枚
* **勝利条件:** 地元で累計 **20点以上** を獲得したラウンドで終了します。最多得点者の勝利です。

---

## 1. 準備

1. **マップ:** 10マスの環状路を配置します。6か所の市場・拠点に山札から1枚ずつ表向きで置きます。
2. **配布:** 各自コマを「マス0：地元」に置きます。手札5枚と木箱1箱を受け取ります。
3. **手番順:** 先手を決めます。時計回りに進めます。

---

## 2. カードと役

* **カード（全60枚）:** 3色（🍵茶・🌾米・🧵布）× 数字1〜5 × 各4枚
  * 端（1, 5）: **2塩**
  * 中（2, 3, 4）: **1塩**
* **役（荷物）:** 同じ色3枚の組み合わせです。塩の合計が基本点になります。
  * **連番:** `2-3-4`（3塩） / `1-2-3`, `3-4-5`（4塩）
  * **同数:** `2-2-2`, `3-3-3`, `4-4-4`（3塩） / `1-1-1`, `5-5-5`（6塩）

---

## 3. 手番の流れ

手番プレイヤーは、次の手順を順番に行います。

1. **移動:** 手札から1枚を出発マスの市場へ出し、その数字分だけ時計回りに進みます。
2. **補充:** 所持している箱の数までカードを引きます（初期1枚、最大4枚）。1枚引くごとに「現在地市場」か「山札」かを選べます。
3. **行動:** 現在地マスで以下を自由に行えます。
   * **荷積み:** 手札の役を空き箱に置きます。直後にカードを3枚補充します（1枚ごとに現在地市場か山札か選べます）。空き箱があれば連続して行えます。
   * **施設アクション:** 現在地マスの施設効果を使います。
4. **手札整理:** 手札が5枚を超える場合、5枚になるまで余分なカードを現在地市場へ戻します。

---

## 4. マップと施設

往路と復路で市場を共有します。

```
[ 0: 地元 ] ─── [ 1: 箱屋 ] ─── [ 2: 街道 ] ─── [ 3: 会所 ] ─── [ 4: 街道 ] ─── [ 5: 港 ]
(納品・得点化)        │               │               │               │            (荷下ろし・塩獲得)
                 [ 箱屋市場 ]    [ 街道市場A ]   [ 会所市場 ]    [ 街道市場B ]
                      │               │               │               │
[ 0: 地元 ] ─── [ 9: 箱屋 ] ─── [ 8: 街道 ] ─── [ 7: 会所 ] ─── [ 6: 街道 ] ─── [ 5: 港 ]
```

| マス | 名称 | 施設アクション | 費用 |
| :--- | :--- | :--- | :--- |
| **0** | **地元** | 箱の塩を得点にします（1塩＝1点）。納品した箱は空になります。納品せず温存もできます。 | 無料 |
| **1, 9** | **箱屋** | 木箱を1箱増やせます（最大4箱）。所持箱が増えると手番の補充上限も増えます。 | 2箱目: 1塩<br>3箱目: 2塩<br>4箱目: 3塩 |
| **2, 8** | **街道** | アクションはありません（市場Aのカードを補充できます）。 | なし |
| **3, 7** | **会所** | 木箱を1箱裏返して「高級箱」にします（出荷ボーナス+3塩）。 | 2塩 |
| **4, 6** | **街道** | アクションはありません（市場Bのカードを補充できます）。 | なし |
| **5** | **港** | 荷物を下ろして塩を獲得します（カードは捨て札にします）。<br>・木箱：基本点そのままの塩<br>・高級箱：基本点 ＋ 3塩 | 無料 |

※費用の塩は手元の箱から支払います（複数箱の合算も可能です）。

---

## 5. 補足ルール

* **山札のリフレッシュ:** 山札が尽きたら、捨て札を混ぜて新しい山札を作ります（市場のカードは残します）。
* **ゲーム終了:** 誰かが累計20点以上に達したラウンドの最終手番まで行い、最多得点者の勝利です（同点は同着勝利です）。
