# ナウキ運び 公式ルール

『ナウキ運び』は、手札で荷物（カードの役）を作り、木箱に積んで港へ運び、手に入れた「塩」を地元へ持ち帰って得点を競うすごろく風カードゲームです。

* **プレイ人数:** 2〜4人
* **プレイ時間:** 15〜20分
* **勝利条件:** いずれかのプレイヤーが地元で累計 **20点以上** を獲得したラウンドでゲーム終了。最も得点が高いプレイヤーの勝利です。

---

## 1. 内容物と準備

### 内容物
* **商品カード:** 60枚（3色 × 数字1〜5 × 各4枚）
* **木箱タイル:** 各プレイヤー最大4箱（裏面は「高級箱」）
* **コマ（商人）:** 各プレイヤー1個

### ゲームの準備
1. **マップの配置:** 10マスの環状路（マス0〜9）を配置します。
2. **市場の初期カード:** 6か所の市場（地元、箱屋、街道A、会所、街道B、港）に、山札からカードを1枚ずつ表向きで置きます。
4. **初期アイテムの配布:** 各プレイヤーに以下を配ります。
   * コマ 1個（マス0「地元」に置きます）
   * 手札 5枚（山札から引きます）
   * 木箱 1箱（最初は1箱だけ持った状態でスタートします）
5. **手番順:** スタートプレイヤーを決め、時計回りに手番を進めます。

---

## 2. カードと役（荷物）

### カードの数字と「塩」の価値
カードには「茶」「米」「布」の3色があり、それぞれ数字1から5が各4枚あります。
数字によって、港で換金できる塩の基本価値が決まります。
* **端の数字（1, 5）:** 2塩
* **中の数字（2, 3, 4）:** 1塩

### 役（同じ色3枚の組み合わせ）
同じ色のカード3枚を組み合わせると役（荷物）になります。役の基本点は、カード3枚の塩の合計値です。
* **連番（連続する3つの数字）:**
  * `2-3-4`: 基本点 3塩
  * `1-2-3`, `3-4-5`: 基本点 4塩
* **同数（同じ3つの数字）:**
  * `2-2-2`, `3-3-3`, `4-4-4`: 基本点 3塩
  * `1-1-1`, `5-5-5`: 基本点 6塩

---

## 3. 手番の流れ

自分の手番が来たら、次の4つのステップを順番に行います。

### ステップ1：移動
手札からカードを1枚選び、**現在いるマスの市場へ表向きで出します**。
出したカードの数字と同じマス数だけ、自分のコマを時計回りに進めます。

### ステップ2：施設アクション（マスの効果を使う）
  止まったマスの施設効果を実行します（詳細は第4章を参照してください）。

### ステップ3：補充
所持している箱の数と同じ枚数、カードを引きます。
* **市場にカードがある場合:** 止まったマスの市場に並んでいる表向きカードから、**好きな1枚を選んで手札に加えます**。
* **市場にカードがない場合:** 山札からランダムに**1枚引きます**。

### ステップ4：荷積み（役を箱に載せる）
手札から役（同色3枚）を1組選び、空いている箱に入れます。
**荷積みの直後、カードを3枚補充します**。（この場合も市場にカードがあれば市場から、なければ山札から引きます。）空いている箱がある限り、何組でも連続で荷積みを行えます。

### ステップ5：手札整理
手番終了時に手札が5枚を超えている場合、手札が5枚になるまで余分なカードを選び、現在地マスの市場へ表向きで置きます。

---

## 4. マップと施設

マップは10マスの環状路です。往路（マス0→5）と復路（マス5→0）の向かい合うマス同士で、同じ市場を共有します。地元と港を含め、**すべてのマスに市場があります**。

* **マス0:** 地元（地元市場）
* **マス1 / マス9:** 箱屋（箱屋市場を共有）
* **マス2 / マス8:** 街道（街道市場Aを共有）
* **マス3 / マス7:** 会所（会所市場を共有）
* **マス4 / マス6:** 街道（街道市場Bを共有）
* **マス5:** 港（港市場）

### 施設一覧

| マス | 施設名 | アクション内容 | 費用 |
| :--- | :--- | :--- | :--- |
| **0** | **地元** | 箱の中の塩を**得点（1塩＝1点）**に変換します。納品した箱は空になり、再び荷物を積めるようになります（塩の温存も可）。 | 無料 |
| **1, 9** | **箱屋** | 新しい木箱を1箱追加します（最大4箱）。**箱が1つ増えるごとに、毎手番の補充枚数も1枚増えます**。 | 2箱目: 1塩<br>3箱目: 3塩<br>4箱目: 7塩 |
| **2, 8** | **街道** | 施設アクションはありません。 | なし |
| **3, 7** | **会所** | 箱を1箱裏返して**大きな箱**に強化します（港での出荷ボーナス+3塩）。 | 2塩 |
| **4, 6** | **街道** | 施設アクションはありません。 | なし |
| **5** | **港** | 箱の荷物を下ろして**塩を獲得**します（出荷）。<br>・**箱:** 役の基本点と同じ塩を獲得<br>・**大きな箱:** 役の基本点 ＋ **ボーナス3塩** を獲得<br>※納品時に**「港町の流行」**が発生します（下記参照）。 | 無料 |

※施設利用の費用（塩）は、手持ちの箱の中にある塩から支払います（複数箱からの合算も可能です）。

#### 港（マス5）のアクション詳細
* **港町の流行:** 荷物を納品した際、山札からカードを1枚めくります。手札にそれと**全く同じカード（同じ色・同じ数字）**を持っている場合、**1枚につき1点**を獲得します。
* **カードの即時シャッフル:** 納品した荷物カードおよび「港町の流行」でめくったカードは、捨て札置き場に送らず、**即時に山札へ戻してシャッフル**します。

---

## 5. ゲームの終了と勝利

* **終了条件:** いずれかのプレイヤーが、地元で累計 **20点以上** を達成したら終了フラグが立ちます。
* **最終手番:** 全プレイヤーの手番数が同じになるよう、そのラウンドの最後のプレイヤー（スタートプレイヤーの右隣）まで手番を行ってゲームを終了します。
* **勝敗:** 最も得点が高いプレイヤーの勝利です。同点の場合は同着勝利とします。

### その他のルール
* **納品・流行カードの循環:** 港で納品された荷物カードおよび「港町の流行」でめくられたカードは、捨て札置き場に送らず、その場で即時に山札へ戻してシャッフルします。
* **山札の補充:** 山札が尽きた場合、捨て札（手札整理等で生じたものがあれば）をよく混ぜて新しい山札を作ります。市場にあるカードはそのまま残します。
