# ナウキ運び 公式ルール

荷物を運んで港で塩にし、地元へ持ち帰って得点を競うすごろく風カードゲームです。

* **プレイ人数 / 時間:** 2〜4人 / 約15〜20分
* **手札上限:** 5枚
* **勝利条件:** 地元で **20点以上** 獲得したプレイヤーが出たラウンドで終了します。全員が同じ手番数をプレイし、最多得点者の勝利となります。

---

## 1. 準備

1. **マップの配置:** 10マスの環状路を作ります。4つの共有市場（マス1-9、2-8、3-7、4-6）と、2つの拠点（マス0地元、マス5港）の計6か所に、山札からカードを1枚ずつ表向きで置きます。
2. **初期配布:** 各自のコマを「マス0：地元」に置きます。手札5枚と木箱1箱を受け取ります。
3. **スタートプレイヤー:** じゃんけんなどで先手を決めます。

---

## 2. カードと役（荷物）

* **カード構成（計60枚）:** 3色（🍵茶・🌾米・🧵布）× 数字1〜5 × 各4枚
  * 数字 1, 5（端）: **2 塩**
  * 数字 2, 3, 4（中）: **1 塩**
* **役（荷物）:** **同じ色3枚** の組み合わせです。カードの塩の合計が基本点になります。
  * **連番（順子）:** `2-3-4`（3塩） / `1-2-3`, `3-4-5`（4塩）
  * **同数（刻子）:** `2-2-2`, `3-3-3`, `4-4-4`（3塩） / `1-1-1`, `5-5-5`（6塩）

---

## 3. 手番の流れ

手番プレイヤーは、次の①〜④を順番に行います。

1. **移動:** 手札から1枚選んで**出発マスの市場へ表向きで置き**、その数字（1〜5）分だけ時計回りに進みます。
2. **補充:** 止まったマスの市場の場札、または山札からカードを引きます（1枚引くごとにどちらか選べます）。初期上限は1枚です（仕入れ所で最大3枚まで増やせます）。上限未満で補充を終えても構いません。
3. **行動:** 止まったマスで、以下を任意の順序・回数で行えます。
   * **荷積み:** 手札の役（同色3枚）を空の荷箱に置きます。**置いた直後に山札から3枚引いて手札を補充します**（空き箱があれば連続して荷積みできます）。
   * **施設アクション:** 止まっているマスの効果を使います（詳細は「4. マップと施設一覧」を参照）。
4. **手札整理:** 手札が5枚を超えている場合、5枚になるまで余分なカードを選び、現在地マスの市場へ戻して手番を終了します。

---

## 4. マップと施設一覧

往路と復路で市場を共有します（例：マス1とマス9は同じ「箱屋市場」を利用します）。

```
[ 0: 地元 ] ─── [ 1: 箱屋 ] ─── [ 2: 仕入れ所 ] ─── [ 3: 会所 ] ─── [ 4: 街道 ] ─── [ 5: 港 ]
(納品・得点化)        │               │                 │               │            (荷下ろし・塩獲得)
                 [ 箱屋市場 ]    [ 仕入市場 ]      [ 会所市場 ]    [ 街道市場 ]
                      │               │                 │               │
[ 0: 地元 ] ─── [ 9: 箱屋 ] ─── [ 8: 仕入れ所 ] ─── [ 7: 会所 ] ─── [ 6: 街道 ] ─── [ 5: 港 ]
```

| マス | 名称 | 施設効果（手番の「行動」で使用できます） | 費用 |
| :--- | :--- | :--- | :--- |
| **0** | **地元** | 箱の塩を勝利点に変換します（1塩＝1点）。納品した箱は空になり再利用できます。納品しない箱の塩は温存できます。 | 無料 |
| **1, 9** | **箱屋** | 新しい荷箱（木箱）を1箱増やせます（最大4箱まで）。 | 2箱目: 1塩<br>3箱目: 2塩<br>4箱目: 3塩 |
| **2, 8** | **仕入れ所** | 手番ごとの補充上限を +1 枚します（初期1枚、最大3枚）。 | 2塩 |
| **3, 7** | **会所** | 木箱を1箱裏返して「高級箱」に強化します（出荷ボーナス+3塩）。 | 2塩 |
| **4, 6** | **街道** | 施設アクションはありません（街道市場のカードを補充できます）。 | - |
| **5** | **港** | 荷物を下ろして箱に塩を獲得します（カードは捨て札にします）。<br>・木箱：基本点そのままの塩<br>・高級箱：基本点 ＋ 3塩 | 無料 |

※費用の塩は、手元の荷箱から支払います（複数箱の合算も可能です）。

---

## 5. 補足ルール

* **山札のリフレッシュ:** 山札が尽きた場合、捨て札をすべてよく混ぜて新しい山札を作ります（市場の場札はそのまま残します）。
* **ゲーム終了:** 誰かが地元で累計20点以上に達したラウンドの最終手番（4番手）まで行い、最も得点が高いプレイヤーの勝利となります（同点の場合は同着勝利です）。
