# ナウキ運び

### 概要
* **プレイ人数:** 2〜4人 / **プレイ時間:** 約15〜20分 / **手札上限:** 5枚固定
* **勝利条件:** 地元（マス0）で **塩（勝利点）を累計20点** 獲得したプレイヤーが出たラウンドでゲーム終了。そのラウンドの4番手（P4）まで全員が同数手番をプレイし、最終得点が最も高いプレイヤーの勝利！

---

### 1. コンポーネント ＆ カード構成
* **カード（計60枚・純粋デッキ）:** 3色（🍵茶・🌾米・🧵布）× 数字1〜5 × 各4枚
  * **数字 1・5（端牌）:** 🧂 **塩 2**
  * **数字 2・3・4（中張牌）:** 🧂 **塩 1**
* **マップ（10マス円環・4×3長方形街道・完全均等配置）:**
  * 🏡 **マス0: 地元**（納品・投資用塩の取り置き・得点化）
  * 🛖 **マス1, 7: 箱屋**（箱の増設: 1・2・3塩）
  * 🧺 **マス2, 8: 仕入れ所**（塩2で補充上限+1、最大3枚）
  * 🏛️ **マス3, 9: 会所**（高級箱化: 2塩）
  * 🛣️ **マス4, 6: 街道**（カード回収 / 山札ドロー）
  * ⚓ **マス5: 港**（荷下ろし: 木箱=素点 / 高級箱=素点＋3塩🔥）
* **荷箱タイル（ダブルサイド・裏表2段階）:**
  * **【表】木箱:** 荷物セットを1つ積載可能 ＋ **港でカードの素点そのままの塩を獲得！**（3〜6塩）
  * **【裏】高級箱:** 荷物セットを1つ積載可能 ＋ **港でカード素点 ＋ 3塩 を獲得！**（6〜9塩）
  * *(※各プレイヤー初期1枚所持、最大4枚まで増設可能)*

```
[ 0: 🏡地元 ] ── [ 1: 🛖箱屋 ] ── [ 2: 🧺仕入れ所 ] ── [ 3: 🏛️会所 ]
     │                                                     │
[ 9: 🏛️会所 ]             【 4×3 長方形 】                [ 4: 🛣️街道 ]
     │                                                     │
[ 8: 🧺仕入れ所 ] ── [ 7: 🛖箱屋 ] ── [ 6: 🛣️街道 ] ─── [ 5: ⚓港 ]
```
> **🌟 往路・復路の美しい対称性**:
> 地元（0）で得た塩を一部手元に残して出発することで、往路（1〜3）でも復路（7〜9）でも自由に施設へ投資できます。

---

### 2. セット（荷物）と塩の計算
**同じ色3枚** で役を作ると、空いている荷箱タイルに積載できる。
* **① 同色順子（同じ色の連番3枚）:** `2-3-4` ＝ **3 塩** / `1-2-3`, `3-4-5` ＝ **4 塩**
* **② 同色刻子（同じ色の同数3枚）:** `2-2-2`, `3-3-3`, `4-4-4` ＝ **3 塩** / `1-1-1`, `5-5-5` ＝ **6 塩**
*(※カードに書かれた塩の合計がそのまま素点になります)*

---

### 3. ゲームの準備とカード循環（デッキ規定）
1. マス0〜9を4×3円環状に並べ、各マスに山札からカードを**1枚ずつ表向き**で置く。
2. 全員コマを**マス0（地元）**に置き、**手札5枚**と**初期荷箱タイル1枚（表向きの木箱）**を受け取る。
3. **山札・捨て札・場札の循環ルール:**
   * 港で荷下ろしされたカードや手札調整で捨てられたカードは、共通の**「捨て札置き場」**に表向きで重ねる。
   * 山札が尽きた場合、**捨て札置き場のカードをすべてシャッフルして新たな山札にする**（※マス上にある場札はそのまま維持する）。

---

### 4. 手番の流れ（3ステップ）

手番プレイヤーは以下の順に実行する。

#### ① 移動
* 手札から1枚選んで**現在地に表向きで置き**、その**数字分だけ時計回りに進む**（1〜5マス）。

#### ② 補充（強化済み上限まで・補充元を毎回選択）
* 移動後、通常は1枚、仕入れ所で強化するたびに最大枚数が1枚増える（最大3枚）。
* 補充上限の範囲で、カードを1枚取るたびに**現在地の場札 / 山札 / 補充終了**を選ぶ。
* 場札からは好きな1枚を選び、取らなかったカードはそのマスに残す。場札がなければ山札を選ぶ。
* 補充後に役を荷箱へ積み、手番の最後に手札が5枚を超えていれば、余分なカードを現在地へ戻す。
* 箱に積んだ荷物は、**地元に戻るまで箱を開けて手札へ戻せない**。

#### ③ 行動（好きな順・組み合わせで実行可）
* **荷積み（面子公開 ＆ 3枚即時補充！）:**
  * 手札のセット（同じ色3枚組）を、空いている自分の荷箱タイル（塩も荷物も入っていない箱）に置いて積載する。
  * 🎴 **面子公開ボーナス:** 荷箱に下ろした瞬間、**山札から即座に3枚引いて手札に補充する**（手札は常に5枚をキープして詰み防止）！
    * ※空き箱が複数あれば、引いたカードで同じ手番中に2つ目・3つ目・4つ目の箱へ連続荷積みも可能！
* **マス効果を使う:** 止まったマスの効果を実行する。

---

### 5. マス効果一覧（箱の運用と投資）

* ⚓ **マス5: 港（荷下ろし ➔ 箱に塩を満載！）**
  * 運んできた荷箱の荷物を下ろし（カードは捨て札へ）、**その荷箱に塩を満載する**。
    * **【表】木箱:** カードの素点そのままの塩が入る！（3〜6塩）
    * **【裏】高級箱:** カード素点 ＋ **3塩の特大ボーナス！**（6〜9塩）

* 🏛️ **マス3, 9: 会所（箱のアップグレード）**
  * 箱に入っている塩から **`2 塩`** 支払い、木箱タイルを1枚 **【裏返す（高級箱にする）】**。

* 🧺 **マス2, 8: 仕入れ所（補充上限の強化）**
  * 箱に入っている塩から **`2 塩`** 支払い、補充上限を **+1枚** する（初期1枚、最大3枚）。
  * 強化はそのマスに止まった手番の行動後に適用され、次の手番から使える。

* 🛖 **マス1, 7: 箱屋（荷箱の増設）**
  * 2箱目は **1塩**、3箱目は **2塩**、4箱目は **3塩** を支払って増設する（最大4箱）。

* 📦 **箱の開封**
  * 荷物入りの箱は地元でのみ開封でき、積んだ3枚を手札へ戻せる。
  * 港では全箱を一括荷下ろしできる。荷下ろしせず温存する箱があってもよい。

* 🏡 **マス0: 地元（箱を選んで納品・得点化）**
  * 塩が入っている荷箱の中から、**どの箱を空にするかを選び（複数可）、その箱の塩をすべて勝利点（1塩＝1点）に変換して納品する**（一括納品も可能）。
  * 納品された箱は**完全に空になり、次の周回で新たな荷物を積載できる**！
  * 納品しなかった箱の塩はそのまま残り、往路（1〜3）などの施設投資の資金として持ち越せる（※ただし塩が入っている箱には荷物を積めない）。
  * 累計 **20点に達したプレイヤーが出たら最終ラウンドに突入**！ そのラウンドの4番手（P4）までプレイして最多得点者が勝利する。

### 6. 面白さ評価システム（AI検証機）の仕組みと結果

`fun_evaluator.js` は、4つの異なるAI戦略を対戦させ、客観的な盤面イベント・統計指標から**「面白さ8軸（各12.5点・合計100点満点）」**を数学的に算出して評価します。

#### ① 8軸面白さ評価の計算ロジック

| 評価軸 | 測定指標と判定基準 | 理想的な状態 |
| :--- | :--- | :--- |
| **🔥 接戦度 (12.5点)** | 1位と2位の点差（平均）、中盤以降の逆転率、同時リーチ発生率 | 最後まで誰が勝つか分からない接戦 |
| **⚖️ 戦略多様性 (12.5点)** | 4大戦略の勝率バランスから**ジニ係数**（0=完全均等）を算出 | 特定の1強戦術がなく、全戦略が拮抗 |
| **⚡ テンポ (12.5点)** | 平均決着巡数（目標15〜20分＝16〜20巡）および巡数の標準偏差 | ダレずに短時間でスッキリ収束する |
| **📦 成長・達成感 (12.5点)** | 平均荷箱増設数、高級箱化率、1人あたりの役完成回数 | 自信の荷箱や手札が強化される満足感 |
| **🧠 悩ましさ (12.5点)** | **客観的ジレンマ発生数**（役破壊・利敵放出・投資分岐）と有効選択肢数 | 毎手番で真剣に悩む良質な葛藤がある |
| **📈 ドラマ性 (12.5点)** | 試合中の順位変動（リードチェンジ回数）および中盤首位の逆転負け率 | 劇的な大逆転劇が自然に発生する |
| **🤝 相互作用 (12.5点)** | 街道マス上カードの争奪回数、同じマスへの着地（経路競合）頻度 | プレイヤー同士の読み合い・インタラクション |
| **🎯 公平性 (12.5点)** | 座順（P1先手〜P4後手）の最大勝率と最小勝率の差（バイアス） | 先手必勝にならず、座順格差が5%以内 |
