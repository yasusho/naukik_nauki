# ナウキ運び

### 概要
* **プレイ人数:** 2〜4人 / **プレイ時間:** 約15〜20分
* **勝利条件:** 地元（マス0）で **塩（勝利点）を累計20点** 獲得したプレイヤーの即時勝利。

---

### 1. コンポーネント ＆ カード構成
* **カード（全60枚）:** 3色（🍵茶・🌾米・🧵布）× 数字1〜5 × 各4枚
  * **数字 1・5:** 🧂 **塩 2**
  * **数字 2・3・4:** 🧂 **塩 1**
* **マップ（8マス円環）:** 偶数マス＝施設 / 奇数マス＝街道
* **個人ボード:** 荷箱（最大3枠）、会所（最大Lv3）、得点トラック

---

### 2. セット（荷物）と塩の計算
同じ色3枚でセットを作ると、荷箱に積載できる。価値は**「カードに描かれた塩の単純合計」**。

---

### 3. ゲームの準備
1. マス0〜7を円環状に並べ、各マスに山札からカードを**1枚ずつ表向き**で置く。
2. 全員コマを**マス0（地元）**に置き、**手札7枚**を配る（初期状態: 荷箱1枠 / 会所Lv1 / 0点）。

---

### 4. 手番の流れ（3ステップ）

手番プレイヤーは以下の順に実行する。

#### ① 移動
* 手札から1枚選んで**現在地に表向きで置き**、その**数字分だけ時計回りに進む**。

#### ② 補充（どちらか選択）
* **A. 山札から引く:** 山札から手札上限（7枚）まで引く。
* **B. マスのカードを全回収:** 現在地にあるカードをすべて手札に加える。
  * ※手札が7枚を超えた場合、超過分を手札から選んで現在地のマスに戻す。
  * ※山札が尽きたら、捨て札をすべてシャッフルして新たな山札にする。

#### ③ 行動（好きな順で実行可）
* **荷箱に積む:** 手札のセット（3枚組）を、空いている荷箱枠に置く。
* **マス効果を使う:** 止まったマスの効果を実行する。

---

### 5. マス効果一覧

> 💡 **経済の原則:** 荷箱のセットは直接強化には使えない。必ず **⚓ 港（マス4）で売却して「塩」に換金** してから、各施設で支払う。

* **⚓ マス4: 港（売却・換金）**
  * 荷箱のセットを売却して、会所レベルに応じた「塩」を荷箱に乗せる（カードは捨て札へ）。
  * 🏛️ **売却レート:** **Lv1＝等価（素の塩） / Lv2＝＋2 塩 / Lv3＝売却値２倍（✕2）！**
    * *(例: Lv3のとき「1-1-1 (6塩)」を売ると一撃で **12塩** に換金！)*

* **🛖 マス2: 箱屋（荷箱拡張）**
  * 換金して荷箱に乗っている「塩」を支払って荷箱枠を拡張する（最大3枠）。
  * **Lv2（2枠目）:** `3 塩支払` / **Lv3（3枠目）:** `5 塩支払`

* **🏛️ マス6: 会所（レート強化）**
  * 換金して荷箱に乗っている「塩」を支払って港の売却レートを強化する（最大Lv3）。
  * **Lv2（港+2塩）:** `4 塩支払` / **Lv3（港2倍!）:** `7 塩支払`

* **🏡 マス0: 地元（納品・得点化）**
  * 荷箱に乗っている「塩」をすべて**勝利点（1塩＝1点）**に変換する。
  * **累計20点に達した時点でゲーム終了、そのプレイヤーの勝利！**

* **🛣️ マス1, 3, 5, 7: 街道**
  * 特殊効果なし（カードの配置・回収のみ）。
