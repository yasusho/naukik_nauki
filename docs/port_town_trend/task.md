# タスクリスト: 「港町の流行」ルールの導入と捨て札即時山札シャッフルの実装

## 概要
港での荷下ろし（納品）時に山札から1枚めくり、手札に全く同じカードがあれば1枚につき1点を獲得するルール「港町の流行」を新設した。
また、納品時や港町の流行で出たカードを即時で山札に混ぜてシャッフルする仕様へと変更し、公式ルール（README.md）および全実装（main.js, fun_evaluator.js, dashboard.js, simulate.js）に反映した。
