# 実装計画: 「港町の流行」ルール導入および捨て札の即時山札シャッフル

港（マス5）で荷物を納品（荷下ろし）した際、山札から1枚めくって手札に同色同数字のカードがあれば1枚につき1点を獲得できる新ルール「港町の流行」を取り入れます。
また、納品時や流行判定で出たカードを捨て札置き場にためるのではなく、即座に山札に戻してシャッフルする仕様へとゲームルールおよびコードベース（ゲーム本体UI・シミュレータ）を一貫して更新します。

---

## ユーザー確認事項 (User Review Required)

- **「港町の流行」の仕様定義**:
  - **発動契機**: 港（マス5）で箱の荷物を下ろす（納品する）ときに発動します。
  - **手順**:
    1. 山札の一番上からカードを1枚めくる（「流行カード」）。
    2. そのプレイヤーの手札を確認し、色・数字が完全に一致するカードが何枚あるかを数える。
    3. 1枚につき1点（勝利点）を即時獲得する（手札のカードは消費せず手元に残る）。
    4. 納品した荷物のカード（各3枚）およびめくった流行カード（1枚）を山札に混ぜて即座にシャッフルする。
  - **獲得対象**: 手札のカード。
  - **獲得点数**: 1枚につき1点（勝利点に直結）。

- **「捨て札の即時山札シャッフル」**:
  - 港で納品されたカードや流行でめくられたカードは、捨て札置き場（`discard`）に送らず、即時に山札（`deck`）へ加えてシャッフルします。
  - これにより、限られた同色同数字カード（各4枚）が即座に山札へ循環し、「港町の流行」の発生率や市場・補充のカードプールがダイナミックに維持されます。

### 2. ゲーム本体 (Web UI)
#### [main.js](file:///c:/Users/yasus/Documents/naukik_nauki/main.js)
- **港アクションの更新**:
  - 人間プレイヤー（`handlePortSellAll` / `handlePortSellBox`）:
    - 荷物カードを取得。
    - 山札から1枚めくる（`trendCard`）。
    - プレイヤーの手札（`me.hand`）の中で `c.type === trendCard.type && c.num === trendCard.num` となる枚数をカウント。
    - 一致枚数 × 1 点をスコア（`score`）に加算。20点以上なら終了フラグを更新。
    - 納品カード＋めくったカードを山札へ戻して `shuffle([...remainingDeck, ...returnedCards, trendCard])`。
    - UIステート（流行カード情報、獲得点、通知メッセージ）を更新し、プレイヤーにポップアップまたは通知バーで視覚的に結果を表示。
  - CPUプレイヤー（AI手番処理内、マス5到達時）:
    - 港で荷下ろし時、山札から1枚めくり、手札の一致枚数分得点加算。
    - 荷物カード＋流行カードを山札へ戻してシャッフル。
    - ゲームログに「港町の流行: [色 数字] が流行！ CPUの手札とX枚一致（+X点）」を表示。
  - UIコンポーネント:
    - 「港町の流行」結果表示用のモーダル／トーストまたは直近流行カード表示枠を追加。
