# 修正内容の確認 (Walkthrough): 「港町の流行」および捨て札の即時山札シャッフル

新ルール**「港町の流行」**の制定と、納品時や流行判定で出たカードを捨て札置き場に送らず**即座に山札へ混ぜてシャッフルする**仕様変更を、公式ルールおよびコードベース（ゲーム本体・シミュレータ）へ完全に反映しました。

---

## 1. ルールと仕様の変更点

### 🌟 新ルール「港町の流行」
- **発動タイミング:** 港（マス5）で荷物を納品（荷下ろし）した際。
- **処理の流れ:**
  1. 山札の一番上からカードを1枚めくる（「流行カード」）。
  2. プレイヤーの手札を確認し、色・数字が完全に一致するカードが何枚あるかを調べる。
  3. **一致するカード1枚につき1点（勝利点）** を即時獲得する。
  4. 納品した荷物カード（各3枚）と、めくった流行カード（1枚）を山札に戻し、即座に全体をシャッフルする。

### 🔄 捨て札の即時山札シャッフル
- 従来は港で荷下ろししたカードが捨て札置き場（`discard`）に蓄積されていましたが、新ルールでは**納品時および港町の流行で出たカードは即座に山札（`deck`）へ加えてシャッフル**されます。
- これにより、全60枚のカードが常に山札へ循環し、枯渇を防ぐとともに流行カードや補充カードのプールが公平に保たれます。
